## How to be listed here

Add a row for yourself in your first pull request. By doing so you confirm
that you have read and accepted `CLA-Individual.md`, and — if you contribute
in the course of employment — that the relevant `CLA-Corporate.md` has been
executed.

Every commit in your pull request must carry a `Signed-off-by:` line, which you
produce with `git commit -s`.
