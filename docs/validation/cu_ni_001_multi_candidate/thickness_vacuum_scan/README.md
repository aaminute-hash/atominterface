## 3. 四个问题的回答

### Q1：γ_int 随厚度怎么变？14.4 Å 已收敛吗？

10.8 → 14.4 Å 有 **+0.0045 J/m²（+7%）的台阶**，14.4 → 18.0 Å 只有
**+0.0004 J/m²（+0.6%）**，已落入 4 候选间离散（0.0007）与文档 §3 单候选
扫描的噪声带内。结论：**14.4 Å 是收敛点，10.8 Å 欠收敛**，与
`docs/validation_cu_ni_001.md` §3 的单候选扫描（0.0573 / 0.0617 / 0.0620）
定量一致——本批 4 候选均值 0.0573 / 0.0617 / 0.0621 复现了同一条曲线，
且 14.4 Å 那行的 0.0617 与多候选正式批的小超胞簇相等（rank1 1×1 为
0.0616，rank2–4 为 0.0617）。即：厚度收敛性与超胞选择无关。

### Q2：γ_int 随真空怎么变？10 到 20 Å 有可检测影响吗？

**没有。** 10、15、20 Å 三组的 γ_Cu、γ_Ni、γ_int 全部逐位相同（见 2.2）。
10 Å 真空对本体系已足够，15 Å 默认值带有裕量。与文档 §4 单候选真空扫描
（10–25 Å 全部相同）结论一致，本批在多候选设置下再次确认。

### Q3：分侧厚度组：n_layers 符合参数吗？γ_int 偏移多少？

符合。`--min-thickness-substrate 18.0 --min-thickness-film 10.8` 切出
**10 层 Cu / 8 层 Ni**（candidates.csv 的 `n_layers_sub=10`、
`n_layers_film=8`，两组扫描的均厚配置在同参数下分别为 10/12 与 6/8，
分侧取的是各自单侧的层数）。分侧旋钮生效。

γ_int = 0.0573 J/m²，比基准（14.4/14.4）**低 0.0044 J/m²（−7%）**，与
「全薄」配置（10.8/10.8，0.0573）几乎相等，远低于「全厚」配置
（18.0/18.0，0.0621）——分侧结果落在两侧均厚值之间并贴近薄膜侧，
因为 γ_int 的厚度依赖几乎全部来自 Ni 侧（见 Q4 与下述分解）。

**分解验证（本组最有信息量的结果）：** 分侧组的 γ_Cu 与 18.0 Å 均厚组
（同为 10 层 Cu）逐位相同（1.4978 vs 1.4978），γ_Ni 与 10.8 Å 均厚组
（同为 8 层 Ni）逐位相同（1.9181 vs 1.9181）。即**每侧的表面能只取决
于该侧的层数，与对侧无关**——这正是 coherent 参考态（strained-coherent
bulk reference + 同层数参考板）设计上要保证的分解性，首次在分侧配置
下得到数值确认。

### Q4：γ_Cu / γ_Ni 随厚度/真空怎么变？是否比 γ_int 更不敏感？

是，且不敏感得多：

- **厚度**：γ_Cu 从 6 → 12 层只变 1.4977 → 1.4979（Δ = 0.0002 J/m²）；
  γ_Ni 从 8 → 14 层变 1.9181 → 1.9185（Δ = 0.0004 J/m²）。同区间 γ_int
  变 0.0048 J/m²，是它们的 10–20 倍。
- **真空**：γ_Cu、γ_Ni 在 10/15/20 Å 间逐位相同（见 2.2）。

表面能是「 slab 减 bulk」的大数之差、且两侧层数通过 `n_surfaces=2` 归一，
很快收敛；γ_int 是表面能之差再叠加粘附功项的小数，层数依赖经 Ni 侧的
应变参考能残差进入，所以唯独它对厚度敏感。这定量支持文档 §9 的判断：
γ_int 是账本里最弱的数，报告它必须同时报告厚度收敛设置。

## 4. 结论

1. 厚度：14.4 Å（8 Cu / 10 Ni 层）已收敛；10.8 Å 欠收敛约 7%。D-1 正式批
   采用 14.4 Å 的选择得到本扫描支持。
2. 真空：10–20 Å 无任何可检测影响，15 Å 默认安全。
3. 分侧厚度：PR #16 的新旋钮按预期工作——层数取各自单侧值，两侧表面能
   逐位复现对应均厚组，γ_int 落在两侧均厚值之间（0.0573，偏薄膜侧）。
4. γ_Cu / γ_Ni 对厚度、真空均远不敏感；γ_int 是唯一需要收敛控制的量。
