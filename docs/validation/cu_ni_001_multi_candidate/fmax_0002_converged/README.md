# fmax 收敛验证：γ_int 的三簇离散是否随 fmax=0.01 → 0.002 消失

与 `F:/tmp/d1_out`（fmax=0.01 正式批）逐参数对照的一次运行，**只改 `--fmax`**。
commit `92dc284`，同一 worktree `F:/tmp/wt-d1`，同一权重、同一 seed、同一批候选。

---

## 0. 结论：假设成立

**三簇差从 0.0049 J/m² 收窄到 0.0002 J/m²（缩小约 25 倍）。**
10 个候选在 fmax=0.002 下全部落在 **0.0567–0.0569 J/m²** 区间内，中位数 0.0567 J/m²，标准差 0.0001 J/m²。

原先的三簇（A: 0.0617 / B: 0.0568 / C: 0.0573）合并为单一数值。
**因此 γ_int 的离散被证实是 `fmax=0.01 eV/Å` 判据下的残余收敛误差，不是物理分歧、不是模型误差、也不是代码 bug。**
